# SpeakMentor AI

SpeakMentor AI 是一款场景化英语口语陪练助手，面向英语学习者、求职者和职场新人，支持在面试、点餐、会议等真实场景下进行英语口语练习。

## 项目定位

用户可以选择练习场景，通过语音输入与 AI 进行英文对话，并获得表达纠错、发音反馈和课后总结报告。
